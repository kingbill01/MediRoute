# Guide d'Utilisation MediRoute

## 📱 Pour les Patients

### 1. Inscription

1. Téléchargez l'application MediRoute ou visitez le site web
2. Cliquez sur "S'inscrire"
3. Remplissez vos informations:
   - Nom et prénom
   - Email
   - Numéro de téléphone
   - Mot de passe
   - Date de naissance
   - Ville et région
4. Cochez "Je suis un patient"
5. Cliquez sur "Créer mon compte"

### 2. Connexion

1. Entrez votre email et mot de passe
2. Cliquez sur "Se connecter"

### 3. Prendre un Rendez-vous

1. Depuis le tableau de bord, cliquez sur "Prendre rendez-vous"
2. Recherchez un médecin par:
   - Spécialité
   - Nom
   - Localisation
3. Sélectionnez un médecin
4. Consultez ses disponibilités
5. Choisissez une date et heure
6. Indiquez le motif de la consultation
7. Confirmez le rendez-vous

### 4. Consulter son Dossier Médical

1. Cliquez sur "Dossier médical" dans le menu
2. Consultez:
   - Historique des consultations
   - Ordonnances
   - Résultats d'analyses
   - Vaccinations
   - Allergies

### 5. En Cas d'Urgence 🚨

#### Sur le site web:
1. Cliquez sur le bouton rouge "URGENCE MÉDICALE"
2. Répondez aux questions du formulaire:
   - Symptômes
   - État de conscience
   - Capacité à respirer
   - Capacité à se déplacer
3. Décrivez la situation
4. Autorisez la géolocalisation
5. Soumettez le formulaire
6. **Vous verrez immédiatement la liste des hôpitaux les plus proches avec:**
   - Distance en km
   - Nombre de lits disponibles
   - Numéro d'urgence
   - Adresse

#### Sur mobile:
1. Ouvrez l'application (connexion non requise)
2. Appuyez sur "🚨 URGENCE MÉDICALE"
3. Suivez les mêmes étapes que sur le web
4. L'application utilisera votre localisation GPS
5. Contactez directement l'hôpital via l'application

## 👨‍⚕️ Pour les Médecins

### 1. Inscription

1. Créez un compte en sélectionnant "Je suis un médecin"
2. Renseignez:
   - Informations personnelles
   - Spécialité
   - Numéro de licence médicale
   - Hôpital d'affiliation
   - Tarif de consultation
   - Années d'expérience

### 2. Gérer son Agenda

1. Accédez à "Mon agenda"
2. Définissez vos disponibilités:
   - Jours de consultation
   - Heures d'ouverture
   - Durée des consultations
3. Acceptez ou refusez les demandes de rendez-vous

### 3. Consulter les Rendez-vous

1. Vue journalière: voir tous les rendez-vous du jour
2. Vue hebdomadaire: planifier la semaine
3. Filtrer par statut:
   - En attente
   - Confirmés
   - Complétés
   - Annulés

### 4. Gérer les Dossiers Patients

1. Avant une consultation, consultez le dossier
2. Pendant la consultation:
   - Ajoutez des notes
   - Enregistrez les signes vitaux
   - Faites un diagnostic
   - Prescrivez des médicaments
   - Demandez des analyses
3. Le patient reçoit automatiquement l'ordonnance

### 5. Rédiger une Ordonnance

1. Depuis un rendez-vous, cliquez sur "Ordonnance"
2. Ajoutez des médicaments:
   - Nom
   - Dosage
   - Fréquence
   - Durée
3. Ajoutez des tests de laboratoire si nécessaire
4. Validez et envoyez

## 🏥 Pour les Administrateurs d'Hôpitaux

### 1. Gérer les Informations de l'Hôpital

1. Accédez au tableau de bord administrateur
2. Mettez à jour:
   - Coordonnées
   - Services disponibles
   - Spécialisations
   - Personnel
   - Équipements

### 2. Gérer les Capacités d'Urgence

**Important**: Mettez à jour régulièrement!

1. Nombre de lits disponibles
2. Disponibilité pour les urgences (Oui/Non)
3. Temps d'attente estimé
4. Disponibilité des ambulances

### 3. Gérer les Demandes d'Urgence

1. Recevez les notifications en temps réel
2. Consultez les détails:
   - Niveau d'urgence
   - Symptômes
   - Distance du patient
3. Acceptez ou transférez la demande
4. Mettez à jour le statut:
   - Reçu
   - En route
   - Arrivé
   - Pris en charge

## 🌍 Fonctionnalités de Géolocalisation

### Trouver les Hôpitaux Proches

1. La fonction "Hôpitaux proches" utilise votre position
2. Filtrez par:
   - Type (public, privé, clinique)
   - Services (urgences, maternité, etc.)
   - Distance
3. Visualisez sur une carte interactive
4. Obtenez l'itinéraire via Google Maps

## ❓ Questions Fréquentes

### Comment annuler un rendez-vous?
1. Allez dans "Mes rendez-vous"
2. Sélectionnez le rendez-vous
3. Cliquez sur "Annuler"
4. Confirmez (au moins 24h avant)

### Comment mettre à jour mon profil?
1. Cliquez sur votre photo de profil
2. Sélectionnez "Paramètres"
3. Modifiez les informations
4. Enregistrez

### Que faire si j'oublie mon mot de passe?
1. Cliquez sur "Mot de passe oublié"
2. Entrez votre email
3. Recevez un lien de réinitialisation
4. Créez un nouveau mot de passe

### Les consultations sont-elles remboursées?
Cela dépend de votre assurance. MediRoute facilite la connexion, mais les modalités de paiement et remboursement sont gérées entre vous, votre médecin, et votre assurance.

### Mes données sont-elles sécurisées?
Oui! Nous utilisons:
- Chiffrement SSL/TLS
- Azure sécurisé
- Conformité RGPD
- Authentification forte
